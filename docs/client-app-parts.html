Client app — parts

Expo app under client/src. Three screens share one session. The table screen is the only place that draws the felt.

Root · app/_layout.tsx
GameSessionProvider game/GameSession.tsx

Holds credentials, the table snapshot, and the socket. Every screen reads it through useGameSession.

Home app/index.tsx

Name, small blind, buy-in. Creates a table and sits down. If you are already seated, a banner returns you to the table.

Join app/join.tsx

Invite link with game id and password. Name, then sit. Missing invite shows an error.

Table app/table.tsx

Felt, seats, dock, menu, sheets, talk, errors. Sends actions back into the session.

Home and join push to /table. Home on the table returns to /. Leave clears the seat and returns home.

screens call
Session GameSession · sessionStore · api · types

api.ts creates a game, joins, and fetches a LiveKit token. sessionStore keeps credentials on the device. The socket applies snapshots and sends fold, check, call, bet, deal, rebuy, admin, and leave.

Table view PokerTableLayout · tableStage

Felt, nine seats, board, pot, bet chips, action dock, menu button, talk button. tableStage is the seat geometry. Copy comes from i18n.

Video media/

useTableVideo starts a LiveKit room from the credentials. Tracks land on seats. The talk button toggles the mic. Web skips native video.
